# Survey Flecha Seca

App de campo para capturar el survey fitosanitario palma por palma desde el teléfono, sin internet.

- Se instala desde Chrome ("Agregar a pantalla principal") y abre sin conexión.
- La base de palmas se carga en cada teléfono desde un archivo de Excel; este repositorio no contiene datos de la finca.
- Cada teléfono exporta su Excel, y la opción "Importar Excel de otro teléfono" une los archivos.

Archivos: `index.html` (la app), `sw.js` (funcionamiento sin internet), `manifest.webmanifest` e `icons/` (instalación).
